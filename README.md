# Создаем анализатор вакансий для HH с интерфейсом в виде сайта

## Система состоит мз сайта с главной страницей, формой поиска и страницей результатов
Поиск работает по 3 позициям
- Город - множественный селектор
- профессия (2-х уровневый фильтр Категория + Профессия) - сножественный селектор
- поиск по ключевым словам
Результат поиска складывается в БД
По результатам выводится аналитика в виде
Списка ТОП5 ключевых навыков для выбранной профессии
Таблица зарплат для выбранных профессий из колонок
- медианная з/п
- количество вакансий
- количество и % вакансий с указанием з/п
- ТОП5 ключевых навыков для профессии
